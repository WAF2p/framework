== Beschreibung

All cloud resources MUST carry mandatory cost allocation tags: cost-center, owner, environment, and workload. These tags are required on all resource types that generate billable costs (compute, storage, database, network, managed services). Tagging MUST be enforced in the CI/CD pipeline; deployments without full tag compliance MUST be blocked or flagged as violations.

== Begründung

[cols="1,3"]
|===
|Risiko |Beschreibung

|*Risk* |Uncontrolled cloud spend erodes budget and project viability.

|*Risk* |High lock-in or debt decisions are made without financial impact visibility.

|===

== Anforderungen

* All cloud resources MUST carry mandatory cost allocation tags: cost-center, owner, environment, and workload.
* These tags are required on all resource types that generate billable costs (compute, storage, database, network, managed services).
* Tagging MUST be enforced in the CI/CD pipeline; deployments without full tag compliance MUST be blocked or flagged as violations.

== Implementierungsleitfaden

1. Document the requirement in a version-controlled policy or standard.
2. Assign ownership and establish a review cadence (e.g., quarterly).
3. Implement the required configuration as code in Terraform or equivalent IaC.

== Checks

=== waf-cost-010.tf.aws.compute-mandatory-tags

*Engine:* `terraform` | *Provider:* aws | *Automated:* Ja

*AWS compute resources must have all mandatory cost allocation tags*

EC2 instances, ECS services, EKS node groups, Lambda functions and other compute resources must carry all mandatory cost allocation tags: cost-center, owner, environment, and workload.

*Scope:* `resource` — `aws_instance`, `aws_launch_template`, `aws_eks_node_group`, `aws_ecs_service`, `aws_lambda_function`, `aws_db_instance`, `aws_rds_cluster`, `aws_elasticache_cluster`, `aws_s3_bucket`, `aws_cloudwatch_log_group`, `stackit_project`, `stackit_container_registry`, `stackit_mysql_instance`, `stackit_opensearch_instance`, `stackit_redis_instance`, `stackit_secret_manager`, `stackit_load_balancer`, `stackit_network`, `stackit_dns_zone`, `stackit_log_service`, `ovh_cloud_project`, `ovh_vps`, `ovh_dedicated_server`, `ovh_ip_loadbalancing`, `hcloud_server`, `hcloud_volume`, `hcloud_network`, `hcloud_load_balancer`, `hcloud_dns_record`

*Assertions:*
* `tags` key exists — Resource is missing the mandatory 'cost-center' tag.
* `tags` key exists — Resource is missing the mandatory 'owner' tag.
* `tags` key exists — Resource is missing the mandatory 'environment' tag.
* `tags` key exists — Resource is missing the mandatory 'workload' tag.

*Remediation:* Use the shared mandatory-tags module to generate the complete tag map. Add module "tags" { source = "../../modules/mandatory-tags"; cost_center = ...; owner = ...; environment = ...; workload = ...; } Then set tags = module.tags.tags on every resource.

.Compliant

[source,terraform]
----
# AWS
module "tags" {
  source      = "../../modules/mandatory-tags"
  cost_center = "fintech-platform"
  owner       = "payments-team"
  environment = "production"
  workload    = "payment-service"
}
resource "aws_instance" "app" {
  ami           = data.aws_ami.ubuntu.id
  instance_type = "t3.medium"
  tags          = module.tags.tags
}

# Azure
resource "azurerm_virtual_machine" "app" {
  name                = "payment-app-vm"
  resource_group_name = azurerm_resource_group.main.name
  location            = "germanywestcentral"
  tags = merge(module.tags.tags, {
    Name = "payment-app-vm"
  })
}

# StackIT (SchwarzIT)
resource "stackit_load_balancer" "app" {
  project_id = stackit_project.main.id
  name       = "payment-app-lb"
  tags = merge(module.tags.tags, {
    Name = "payment-app-lb"
  })
}

# OVH
resource "ovh_cloud_project_instance" "app" {
  project_id = ovh_cloud_project.main.id
  name       = "payment-app-vm"
  flavor     = "b2-7"
  image      = "Ubuntu 22.04"
  tags = merge(module.tags.tags, {
    Name = "payment-app-vm"
  })
}

# Hetzner Cloud
resource "hcloud_server" "app" {
  name        = "payment-app-server"
  server_type = "cx22"
  location    = "fsn1"
  labels = merge(module.tags.tags, {
    Name = "payment-app-server"
  })
}
----

.Non-Compliant

[source,terraform]
----
resource "aws_instance" "app" {
  ami           = data.aws_ami.ubuntu.id
  instance_type = "t3.medium"
  tags = {
    Name = "payment-app"
    # Missing: cost-center, owner, environment, workload
  }
}
----

=== waf-cost-010.tf.azurerm.resource-group-mandatory-tags

*Engine:* `terraform` | *Provider:* azurerm | *Automated:* Ja

*Azure resource groups must have all mandatory cost allocation tags*

Azure resource groups must carry all mandatory cost allocation tags. Tags applied to resource groups propagate to child resources through Azure Cost Management.

*Scope:* `resource` — `azurerm_resource_group`, `azurerm_virtual_machine`, `azurerm_storage_account`, `azurerm_sql_database`, `azurerm_kubernetes_cluster`, `stackit_project`, `stackit_container_registry`, `stackit_mysql_instance`, `stackit_opensearch_instance`, `stackit_redis_instance`, `stackit_secret_manager`, `ovh_cloud_project`, `ovh_vps`, `ovh_dedicated_server`, `hcloud_server`, `hcloud_volume`, `hcloud_network`, `hcloud_load_balancer`

*Assertions:*
* `tags` key exists — Azure resource is missing the mandatory 'cost-center' tag.
* `tags` key exists — Azure resource is missing the mandatory 'owner' tag.
* `tags` key exists — Azure resource is missing the mandatory 'environment' tag.
* `tags` key exists — Azure resource is missing the mandatory 'workload' tag.

*Remediation:* Add all mandatory tags to Azure resources. For resource groups, ensure tags include cost-center, owner, environment, and workload. Use Azure Policy to enforce tag inheritance.

.Compliant

[source,terraform]
----
resource "azurerm_resource_group" "main" {
  name     = "rg-payment-service-prod"
  location = var.location
  tags = {
    cost-center = "fintech-platform"
    owner       = "payments-team"
    environment = "production"
    workload    = "payment-service"
    managed-by  = "terraform"
  }
}
----

.Non-Compliant

[source,terraform]
----
resource "azurerm_resource_group" "main" {
  name     = "rg-payment-service-prod"
  location = var.location
  # Missing all mandatory tags – WAF-COST-010 violation
}
----

=== waf-cost-010.tf.google.project-labels-mandatory

*Engine:* `terraform` | *Provider:* google | *Automated:* Ja

*GCP projects and billable resources must have mandatory cost allocation labels*

GCP projects must define labels for cost-center, owner, environment, and workload. Billable resources such as google_compute_instance, google_storage_bucket, and google_container_cluster must carry the same labels so cost allocation is possible via GCP Cost Management labels.

*Scope:* `resource` — `google_project`, `google_compute_instance`, `google_storage_bucket`, `google_container_cluster`

*Assertions:*
* `labels` key exists — GCP resource is missing the mandatory 'cost-center' label.
* `labels` key exists — GCP resource is missing the mandatory 'owner' label.
* `labels` key exists — GCP resource is missing the mandatory 'environment' label.
* `labels` key exists — GCP resource is missing the mandatory 'workload' label.

*Remediation:* Set labels on the google_project and on every billable resource. Use a shared labels module and apply it consistently. For BigQuery datasets, also set default_table_expiration_ms where applicable.

.Compliant

[source,terraform]
----
resource "google_project" "payment" {
  name       = "payment-service-prod"
  project_id = "payment-service-prod-123"
  labels = {
    cost-center = "fintech-platform"
    owner       = "payments-team"
    environment = "production"
    workload    = "payment-service"
  }
}

resource "google_compute_instance" "app" {
  name         = "vm-payment-app"
  machine_type = "e2-medium"
  zone         = var.zone

  labels = merge(module.mandatory_tags.labels, {
    cost-center = "fintech-platform"
    owner       = "payments-team"
    environment = "production"
    workload    = "payment-service"
  })
}
----

.Non-Compliant

[source,terraform]
----
resource "google_compute_instance" "app" {
  name         = "vm-payment-app"
  machine_type = "e2-medium"
  zone         = var.zone
  # Missing mandatory cost allocation labels
}
----
