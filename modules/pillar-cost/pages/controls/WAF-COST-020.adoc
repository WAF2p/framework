== Description

Cost budgets MUST be defined as IaC resources (not manually in cloud console UIs) for each cloud account, subscription, or project. Budget alerts MUST be configured at 80% and 100% of the budget limit and automatically routed to the workload owner and FinOps team. Budget resources in IaC ensure they are version-controlled, reviewable, and reproducible.

== Rationale

[cols="1,3"]
|===
|Risk |Description

|*Risk* |Uncontrolled cloud spend erodes budget and project viability.

|*Risk* |High lock-in or debt decisions are made without financial impact visibility.

|===

== Requirements

* Cost budgets MUST be defined as IaC resources (not manually in cloud console UIs) for each cloud account, subscription, or project.
* Budget alerts MUST be configured at 80% and 100% of the budget limit and automatically routed to the workload owner and FinOps team.

== Implementation Guidance

1. Document the requirement in a version-controlled policy or standard.
2. Assign ownership and establish a review cadence (e.g., quarterly).

== Checks

=== waf-cost-020.tf.aws.budgets-budget-exists

*Engine:* `terraform` | *Provider:* aws | *Automated:* Yes

*AWS budget must be defined as IaC resource*

An aws_budgets_budget resource must exist in the Terraform configuration. Budgets set only in the AWS Console are not version-controlled and may be deleted or modified without audit trail.

*Scope:* `resource` — `aws_budgets_budget`

*Assertions:*
* `budget_type` equals `COST` — Budget must be of type COST for cloud spend tracking.
* `time_unit` in `['MONTHLY', 'QUARTERLY', 'DAILY']` — Budget time unit must be MONTHLY or QUARTERLY.

*Remediation:* Add an aws_budgets_budget resource to your Terraform configuration. Set budget_type = "COST", time_unit = "MONTHLY", and configure notification blocks for 80% and 100% thresholds.

.Compliant

[source,terraform]
----
resource "aws_budgets_budget" "workload_monthly" {
  name         = "payment-service-prod-monthly"
  budget_type  = "COST"
  limit_amount = "5000"
  limit_unit   = "USD"
  time_unit    = "MONTHLY"

  notification {
    comparison_operator        = "GREATER_THAN"
    threshold                  = 80
    threshold_type             = "PERCENTAGE"
    notification_type          = "ACTUAL"
    subscriber_email_addresses = ["payments-team@company.com"]
  }

  notification {
    comparison_operator        = "GREATER_THAN"
    threshold                  = 100
    threshold_type             = "PERCENTAGE"
    notification_type          = "ACTUAL"
    subscriber_email_addresses = ["payments-team@company.com", "finops@company.com"]
  }
}
----

.Non-Compliant

[source,terraform]
----
# No aws_budgets_budget resource defined.
# Budget was set manually in AWS Console – not reproducible, not version-controlled.
----

=== waf-cost-020.tf.azurerm.consumption-budget-defined

*Engine:* `terraform` | *Provider:* azurerm | *Automated:* Yes

*Azure consumption budget must be defined as IaC resource*

An azurerm_consumption_budget_resource_group or azurerm_consumption_budget_subscription resource must exist in the Terraform configuration for Azure spending control.

*Scope:* `resource` — `azurerm_consumption_budget_resource_group`, `azurerm_consumption_budget_subscription`, `azurerm_consumption_budget_management_group`

*Assertions:*
* `amount` greater than or equal `1` — Budget amount must be greater than 0.

*Remediation:* Add an azurerm_consumption_budget_resource_group or azurerm_consumption_budget_subscription resource to your Terraform configuration with appropriate notification thresholds.

.Compliant

[source,terraform]
----
resource "azurerm_consumption_budget_resource_group" "main" {
  name              = "payment-service-monthly-budget"
  resource_group_id = azurerm_resource_group.main.id
  amount            = 5000
  time_grain        = "Monthly"

  time_period {
    start_date = "2025-01-01T00:00:00Z"
  }

  notification {
    enabled        = true
    threshold      = 80
    operator       = "GreaterThan"
    threshold_type = "Actual"
    contact_emails = ["payments-team@company.com"]
  }

  notification {
    enabled        = true
    threshold      = 100
    operator       = "GreaterThan"
    threshold_type = "Actual"
    contact_emails = ["payments-team@company.com", "finops@company.com"]
  }
}
----

.Non-Compliant

[source,terraform]
----
# No azurerm_consumption_budget_* resource defined.
# No automated budget control for this Azure workload.
----

=== waf-cost-020.tf.google.billing-budget-exists

*Engine:* `terraform` | *Provider:* google | *Automated:* Yes

*GCP billing budget must be defined as IaC resource*

A google_billing_budget resource must exist in the Terraform configuration. GCP budgets set only in the Cloud Console are not version-controlled and may be modified without audit trail.

*Scope:* `resource` — `google_billing_budget`

*Assertions:*
* `billing_account` attribute exists — GCP billing budget must reference a billing account.
* `threshold_rules` attribute exists — GCP billing budget must define threshold rules for alerts.

*Remediation:* Add a google_billing_budget resource to your Terraform configuration. Define billing_account, display_name, amount, and threshold_rules for 80% and 100% of the budget.

.Compliant

[source,terraform]
----
resource "google_billing_budget" "workload_monthly" {
  billing_account = data.google_billing_account.main.id
  display_name    = "payment-service-prod-monthly"

  amount {
    specified_amount {
      currency_code = "EUR"
      units         = "5000"
    }
  }

  threshold_rules {
    threshold_percent = 80
  }

  threshold_rules {
    threshold_percent = 100
  }

  all_updates_rule {
    monitoring_notification_channels = [
      google_monitoring_notification_channel.finops.id,
      google_monitoring_notification_channel.owner.id,
    ]
    disable_default_iam_recipients   = false
  }
}
----

.Non-Compliant

[source,terraform]
----
# No google_billing_budget resource defined.
# Budget was set manually in GCP Console – not reproducible, not version-controlled.
----
