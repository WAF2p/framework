== Beschreibung

All persistent compute resources (EC2 instances, VMs, RDS instances, Kubernetes node groups) MUST carry a 'rightsizing-reviewed' tag with the date of the last review (ISO 8601, YYYY-MM-DD). Reviews must be performed at least every 90 days. Resources tagged with a review date older than 90 days are considered non-compliant. Idle detection must be configured for all compute workloads (CPU utilization < 5% over 7 days triggers an alert).

== Begründung

[cols="1,3"]
|===
|Risiko |Beschreibung

|*Risk* |Unreviewed compute resources permanently lead to over-provisioning and cloud waste.

|*Risk* |Missing rightsizing evidence complicates FinOps reviews and budget accountability.

|===

== Anforderungen

* All persistent compute resources (EC2 instances, VMs, RDS instances, Kubernetes node groups) MUST carry a 'rightsizing-reviewed' tag with the date of the last review (ISO 8601, YYYY-MM-DD).
* Reviews must be performed at least every 90 days.
* Idle detection must be configured for all compute workloads (CPU utilization < 5% over 7 days triggers an alert).

== Implementierungsleitfaden

1. Document the requirement in a version-controlled policy or standard.
2. Assign ownership and establish a review cadence (e.g., quarterly).
3. Implement the required configuration as code in Terraform or equivalent IaC.

== Checks

=== waf-cost-030.tf.aws.ec2-rightsizing-tag-required

*Engine:* `terraform` | *Provider:* aws | *Automated:* Ja

*EC2 instances must have 'rightsizing-reviewed' tag*

All EC2 instances must carry a 'rightsizing-reviewed' tag with the date (YYYY-MM-DD) of the last rightsizing review. This tag proves active resource management and enables automated detection of resources that have not been reviewed within 90 days.

*Scope:* `resource` — `aws_instance`, `aws_launch_template`

*Assertions:*
* `tags` key exists — EC2 instance is missing the 'rightsizing-reviewed' tag. All compute resources must be actively reviewed.

*Remediation:* Add 'rightsizing-reviewed' tag to all EC2 instances and launch templates. Value format: YYYY-MM-DD (ISO 8601 date of last review). Example: rightsizing-reviewed = "2025-03-01" Schedule the next review within 90 days.

.Compliant

[source,terraform]
----
resource "aws_instance" "app" {
  ami           = data.aws_ami.ubuntu.id
  instance_type = "t3.medium"
  tags = merge(module.mandatory_tags.tags, {
    rightsizing-reviewed = "2025-03-01"
    rightsizing-result   = "no-change"
    capacity-commitment  = "on-demand"
  })
}
----

.Non-Compliant

[source,terraform]
----
resource "aws_instance" "app" {
  ami           = data.aws_ami.ubuntu.id
  instance_type = "t3.medium"
  tags = {
    cost-center = "fintech-platform"
    owner       = "payments-team"
    environment = "production"
    workload    = "payment-service"
    # Missing: rightsizing-reviewed – WAF-COST-030 violation
  }
}
----

=== waf-cost-030.tf.azurerm.vm-rightsizing-tag

*Engine:* `terraform` | *Provider:* azurerm | *Automated:* Ja

*Azure VMs must have 'rightsizing-reviewed' tag*

All Azure Virtual Machines must carry a 'rightsizing-reviewed' tag with the ISO 8601 date of the last rightsizing review, proving active management of compute costs.

*Scope:* `resource` — `azurerm_virtual_machine`, `azurerm_linux_virtual_machine`, `azurerm_windows_virtual_machine`, `azurerm_kubernetes_cluster`

*Assertions:*
* `tags` key exists — Azure VM is missing 'rightsizing-reviewed' tag.

*Remediation:* Add 'rightsizing-reviewed' tag to all Azure compute resources. Use Azure Advisor recommendations to inform the rightsizing review.

.Compliant

[source,terraform]
----
resource "azurerm_linux_virtual_machine" "app" {
  name                = "vm-payment-app-prod"
  resource_group_name = azurerm_resource_group.main.name
  location            = var.location
  size                = "Standard_D2s_v3"
  tags = merge(local.mandatory_tags, {
    "rightsizing-reviewed" = "2025-03-01"
    "rightsizing-result"   = "no-change"
  })
}
----

.Non-Compliant

[source,terraform]
----
resource "azurerm_linux_virtual_machine" "app" {
  name                = "vm-payment-app-prod"
  resource_group_name = azurerm_resource_group.main.name
  location            = var.location
  size                = "Standard_D8s_v3"  # May be oversized; no review proof
  # Missing: rightsizing-reviewed tag
}
----
