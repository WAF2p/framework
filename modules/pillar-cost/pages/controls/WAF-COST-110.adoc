== Description

Workloads that tolerate interruption MUST use Spot/Preemptible instances by default unless business justification documents on-demand use. IaC definitions MUST tag interruptible workloads with spot-eligibility and maximum Spot price or eviction policy. Auto Scaling Groups and Managed Instance Groups SHOULD define mixed instance policies combining Spot and On-Demand capacity. Documentation MUST cover workload interruption handling and fallback behavior.

== Rationale

[cols="1,3"]
|===
|Risk |Description

|*Risk* |Always using on-demand compute for interruptible workloads increases cost without reliability benefit.

|*Risk* |Undocumented Spot usage leads to inconsistent financial planning and surprise evictions.

|===

== Requirements

* Workloads that tolerate interruption MUST use Spot/Preemptible instances by default unless business justification documents on-demand use.
* IaC definitions MUST tag interruptible workloads with spot-eligibility and maximum Spot price or eviction policy.
* Auto Scaling Groups and Managed Instance Groups SHOULD define mixed instance policies combining Spot and On-Demand capacity.
* Documentation MUST cover workload interruption handling and fallback behavior.

== Implementation Guidance

. Document the requirement in a version-controlled policy, ADR, or standard.
. Assign ownership and establish a review cadence (e.g., quarterly).
. Implement the required configuration as code in Terraform or equivalent IaC.
