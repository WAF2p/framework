== Beschreibung

All data transfers MUST be designed to minimize unnecessary movement across network boundaries. Cross-region data transfers MUST be justified; same-region communication MUST be preferred. Content Delivery Networks (CDN) MUST be used for all user-facing static and semi-static content. HTTP compression (gzip/brotli) MUST be enabled for all API responses larger than 1KB. VPC Endpoints MUST be used for AWS service communication to avoid internet gateway egress. Data transfer optimization is both a cost control and a carbon reduction measure: every byte transferred consumes network energy; minimizing transfers minimizes emissions.

== Checks

=== waf-sus-080.tf.aws.cloudfront-compression

*Engine:* `terraform` | *Provider:* aws | *Automated:* Ja

*CloudFront distributions must enable compression*

CloudFront distributions must have compress = true on all cache behaviors to automatically compress compressible content (text, JSON, HTML, CSS, JavaScript) before delivery. This reduces data transfer volume by 60-80% for text content.

*Scope:* `resource` — `aws_cloudfront_distribution`

*Assertions:*
* `default_cache_behavior.compress` is true — CloudFront distribution does not have compression enabled – enable compress = true for 60-80% transfer reduction.

*Remediation:* Set compress = true on all cache_behavior and default_cache_behavior blocks in the CloudFront distribution. CloudFront will automatically compress eligible responses (text/html, text/css, application/json, etc.) using gzip or brotli.

.Compliant

[source,terraform]
----
resource "aws_cloudfront_distribution" "web" {
  default_cache_behavior {
    allowed_methods        = ["GET", "HEAD"]
    cached_methods         = ["GET", "HEAD"]
    target_origin_id       = "web-origin"
    viewer_protocol_policy = "redirect-to-https"
    compress               = true  # 60-80% transfer reduction for text content
  }
  # ...
}
----

.Non-Compliant

[source,terraform]
----
resource "aws_cloudfront_distribution" "web" {
  default_cache_behavior {
    allowed_methods        = ["GET", "HEAD"]
    cached_methods         = ["GET", "HEAD"]
    target_origin_id       = "web-origin"
    viewer_protocol_policy = "redirect-to-https"
    compress               = false  # WAF-SUS-080 Violation: uncompressed delivery
  }
}
----

=== waf-sus-080.tf.aws.vpc-endpoint-s3

*Engine:* `terraform` | *Provider:* aws | *Automated:* Ja

*VPC should have S3 and DynamoDB gateway endpoints to avoid internet egress*

S3 and DynamoDB gateway VPC Endpoints allow EC2 instances and Lambda functions to communicate with these services through the AWS private network instead of through an internet gateway. This eliminates internet data transfer charges and energy, as the traffic stays within AWS's backbone network.

*Scope:* `resource` — `aws_vpc_endpoint`

*Assertions:*
* `service_name` not empty — VPC endpoint has no service_name – check configuration.

*Remediation:* Create gateway VPC endpoints for com.amazonaws.REGION.s3 and com.amazonaws.REGION.dynamodb in each VPC. Associate them with all route tables. For interface endpoints (STS, ECR, CloudWatch, SSM): create them in private subnets to eliminate all internet gateway dependencies.

.Compliant

[source,terraform]
----
resource "aws_vpc_endpoint" "s3" {
  vpc_id            = aws_vpc.main.id
  service_name      = "com.amazonaws.${var.region}.s3"
  vpc_endpoint_type = "Gateway"
  route_table_ids   = aws_route_table.private[*].id
  tags = {
    Name    = "s3-gateway-endpoint"
    purpose = "eliminate-internet-egress"
  }
}

resource "aws_vpc_endpoint" "dynamodb" {
  vpc_id            = aws_vpc.main.id
  service_name      = "com.amazonaws.${var.region}.dynamodb"
  vpc_endpoint_type = "Gateway"
  route_table_ids   = aws_route_table.private[*].id
}
----

.Non-Compliant

[source,terraform]
----
# VPC with no endpoints – all AWS service traffic goes via internet gateway
resource "aws_vpc" "main" {
  cidr_block = "10.0.0.0/16"
  # WAF-SUS-080 Warning: no VPC endpoints configured
}
----

=== waf-sus-080.tf.azurerm.cdn-compression

*Engine:* `terraform` | *Provider:* azurerm | *Automated:* Ja

*Azure CDN endpoints must have compression enabled*

Azure CDN endpoints should have compression enabled to reduce data transfer volume for compressible content types. Without compression, each user receives the full uncompressed payload, multiplying network energy consumption.

*Scope:* `resource` — `azurerm_cdn_endpoint`

*Assertions:*
* `is_compression_enabled` is true — Azure CDN endpoint has compression disabled – enable for significant transfer reduction.

*Remediation:* Set is_compression_enabled = true and provide content_types_to_compress list including text/html, text/css, application/json, application/javascript. Ensure origin also supports compressed responses or configure CDN-level compression.

.Compliant

[source,terraform]
----
resource "azurerm_cdn_endpoint" "web" {
  name                = "web-cdn"
  profile_name        = azurerm_cdn_profile.main.name
  resource_group_name = var.resource_group_name
  location            = "global"
  origin_host_header  = azurerm_storage_account.web.primary_blob_host

  is_compression_enabled = true
  content_types_to_compress = [
    "text/html",
    "text/css",
    "application/json",
    "application/javascript",
    "image/svg+xml",
  ]
}
----

.Non-Compliant

[source,terraform]
----
resource "azurerm_cdn_endpoint" "web" {
  name                   = "web-cdn"
  profile_name           = azurerm_cdn_profile.main.name
  resource_group_name    = var.resource_group_name
  location               = "global"
  is_compression_enabled = false  # WAF-SUS-080 Violation
}
----

=== waf-sus-080.tf.google.backend-compression

*Engine:* `terraform` | *Provider:* google | *Automated:* Ja

*GCP backend services and buckets should have compression enabled*

GCP backend services (global and regional) and backend buckets used with Cloud CDN should enable compression to reduce outbound data transfer and energy consumption.

*Scope:* `resource` — `google_compute_backend_service`, `google_compute_backend_bucket`

*Assertions:*
* `compression_mode` equals `AUTOMATIC` — GCP backend service/bucket should have compression_mode set to AUTOMATIC.

*Remediation:* Set compression_mode = "AUTOMATIC" on google_compute_backend_service and google_compute_backend_bucket where supported by Cloud CDN.

.Compliant

[source,terraform]
----
resource "google_compute_backend_service" "api" {
  name             = "api-backend"
  compression_mode = "AUTOMATIC"
  enable_cdn       = true
}
----

.Non-Compliant

[source,terraform]
----
resource "google_compute_backend_service" "api" {
  name             = "api-backend"
  compression_mode = "DISABLED"
}
----
