= WAF-REL-110 – Circuit Breaker, Backpressure und Rate Limiting müssen für Downstream-Abhängigkeiten definiert sein

== Beschreibung

Every downstream HTTP/gRPC dependency MUST have explicit timeout, retry, circuit breaker, and bulkhead configuration. Services MUST propagate backpressure instead of accepting unbounded load. Rate limits MUST protect backends from accidental or malicious overload. Configuration MUST be observable through metrics and tested via chaos or fault injection.

== Begründung

[cols="1,3"]
|===
|Risiko |Beschreibung

|*Risk* |Cascading failures spread when a single slow dependency saturates all callers.

|*Risk* |Unbounded retries during outages amplify load and prevent recovery of failing services.

|===

== Anforderungen

* Every downstream HTTP/gRPC dependency MUST have explicit timeout, retry, circuit breaker, and bulkhead configuration.
* Services MUST propagate backpressure instead of accepting unbounded load.
* Rate limits MUST protect backends from accidental or malicious overload.
* Configuration MUST be observable through metrics and tested via chaos or fault injection.

== Implementierungsleitfaden

. Document the requirement in a version-controlled policy, ADR, or standard.
. Assign ownership and establish a review cadence (e.g., quarterly).
. Implement the required configuration as code in Terraform or equivalent IaC.
