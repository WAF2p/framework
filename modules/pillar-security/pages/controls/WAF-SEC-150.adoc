== Beschreibung

All virtual machines, bare-metal servers, and container hosts MUST receive automated security patches within defined SLAs. Critical vulnerabilities MUST be remediated within 7 days and high vulnerabilities within 30 days. Endpoint Detection and Response (EDR) MUST be deployed on all production instances. Patch compliance and scan results MUST be centrally reported and reviewed.

== Begründung

[cols="1,3"]
|===
|Risiko |Beschreibung

|*Risk* |Unpatched operating systems and endpoints are primary entry points for malware and lateral movement.

|*Risk* |Missing EDR delays detection of compromised instances and impedes incident response.

|===

== Anforderungen

* All virtual machines, bare-metal servers, and container hosts MUST receive automated security patches within defined SLAs.
* Critical vulnerabilities MUST be remediated within 7 days and high vulnerabilities within 30 days.
* Endpoint Detection and Response (EDR) MUST be deployed on all production instances.
* Patch compliance and scan results MUST be centrally reported and reviewed.

== Implementierungsleitfaden

. Document the requirement in a version-controlled policy, ADR, or standard.
. Assign ownership and establish a review cadence (e.g., quarterly).
. Implement the required configuration as code in Terraform or equivalent IaC.
