== Description

All container images MUST have vulnerability scanning enabled at the registry level using enhanced scanning (Amazon Inspector) or equivalent. Container images containing critical or high CVEs MUST NOT be deployed to production environments without a documented exception and compensating control. ECR repositories MUST use immutable tags to prevent image tampering after push. A documented patch management process MUST exist with defined SLAs: critical CVEs remediated within 72 hours, high CVEs within 7 days, medium within 30 days. OS-level patching for EC2 instances and EKS nodes MUST be automated via AWS Systems Manager Patch Manager.

== Rationale

[cols="1,3"]
|===
|Risk |Description

|*Risk* |Unscanned container images frequently contain known vulnerabilities exploitable in production.

|*Risk* |Missing SBOMs and scan results complicate supply-chain audits and incident response.

|===

== Requirements

* All container images MUST have vulnerability scanning enabled at the registry level using enhanced scanning (Amazon Inspector) or equivalent.
* Container images containing critical or high CVEs MUST NOT be deployed to production environments without a documented exception and compensating control.
* ECR repositories MUST use immutable tags to prevent image tampering after push.
* A documented patch management process MUST exist with defined SLAs: critical CVEs remediated within 72 hours, high CVEs within 7 days, medium within 30 days.
* OS-level patching for EC2 instances and EKS nodes MUST be automated via AWS Systems Manager Patch Manager.

== Implementation Guidance

1. Document the requirement in a version-controlled policy or standard.
2. Assign ownership and establish a review cadence (e.g., quarterly).
3. Implement the required configuration as code in Terraform or equivalent IaC.

== Checks

=== waf-sec-070.tf.aws.ecr-image-scanning

*Engine:* `terraform` | *Provider:* aws | *Automated:* Yes

*ECR repositories must have image scanning enabled*

All aws_ecr_repository resources must have an image_scanning_configuration block with scan_on_push = true to ensure every pushed image is immediately scanned for known vulnerabilities.

*Scope:* `resource` — `aws_ecr_repository`

*Assertions:*
* `image_scanning_configuration` attribute exists — ECR repository must have image_scanning_configuration block defined with scan_on_push = true.

*Remediation:* Add an image_scanning_configuration block to all aws_ecr_repository resources:\n  image_scanning_configuration { scan_on_push = true }\nFor enhanced scanning, enable Amazon Inspector at the account level and configure continuous ECR scanning via aws_inspector2_enabler resource.

.Compliant

[source,terraform]
----
resource "aws_ecr_repository" "app" {
  name                 = "my-application"
  image_tag_mutability = "IMMUTABLE"
  image_scanning_configuration {
    scan_on_push = true
  }
  encryption_configuration {
    encryption_type = "KMS"
    kms_key         = aws_kms_key.ecr.arn
  }
}
----

.Non-Compliant

[source,terraform]
----
resource "aws_ecr_repository" "app" {
  name = "my-application"
  # image_scanning_configuration not set – WAF-SEC-070 violation
  # image_tag_mutability defaults to MUTABLE – WAF-SEC-070 violation
}
----

=== waf-sec-070.tf.aws.ecr-immutable-tags

*Engine:* `terraform` | *Provider:* aws | *Automated:* Yes

*ECR repositories must use immutable image tags*

All aws_ecr_repository resources must have image_tag_mutability = 'IMMUTABLE' to prevent overwriting of existing image tags, which could allow supply chain attacks by replacing a trusted image with a malicious one.

*Scope:* `resource` — `aws_ecr_repository`

*Assertions:*
* `image_tag_mutability` equals `IMMUTABLE` — ECR repository MUST use immutable tags (image_tag_mutability = 'IMMUTABLE') to prevent image tampering.

*Remediation:* Set image_tag_mutability = "IMMUTABLE" on all aws_ecr_repository resources. Update deployment pipelines to reference images by digest (sha256:...) rather than mutable tags like 'latest'. Implement a tagging strategy using semantic versioning (e.g., v1.2.3) combined with immutability for full traceability.

.Compliant

[source,terraform]
----
resource "aws_ecr_repository" "app" {
  name                 = "my-application"
  image_tag_mutability = "IMMUTABLE"
  image_scanning_configuration {
    scan_on_push = true
  }
}
----

.Non-Compliant

[source,terraform]
----
resource "aws_ecr_repository" "app" {
  name                 = "my-application"
  image_tag_mutability = "MUTABLE"  # WAF-SEC-070 violation: allows tag overwrite
}
----
