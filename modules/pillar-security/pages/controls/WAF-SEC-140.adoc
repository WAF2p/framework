== Description

All internet-facing applications and APIs MUST be protected by a Web Application Firewall (WAF) with managed rule sets. Distributed Denial-of-Service (DDoS) protection MUST be enabled at the network and application layers. WAF rules MUST block common attack patterns (OWASP Top 10) and be reviewed quarterly. Rate limiting MUST be configured to mitigate abuse and volumetric attacks.

== Rationale

[cols="1,3"]
|===
|Risk |Description

|*Risk* |Unprotected public endpoints are directly exposed to SQL injection, XSS, and other OWASP Top 10 attacks.

|*Risk* |Missing DDoS protection allows trivial disruption of services by saturating network or application capacity.

|===

== Requirements

* All internet-facing applications and APIs MUST be protected by a Web Application Firewall (WAF) with managed rule sets.
* Distributed Denial-of-Service (DDoS) protection MUST be enabled at the network and application layers.
* WAF rules MUST block common attack patterns (OWASP Top 10) and be reviewed quarterly.
* Rate limiting MUST be configured to mitigate abuse and volumetric attacks.

== Implementation Guidance

. Document the requirement in a version-controlled policy, ADR, or standard.
. Assign ownership and establish a review cadence (e.g., quarterly).
. Implement the required configuration as code in Terraform or equivalent IaC.
