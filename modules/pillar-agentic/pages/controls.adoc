= Agentic – Controls (WAF-AGN)
:page-navtitle: Controls (WAF-AGN)
:page-toc: right
:description: WAF++ – The 10 measurable controls of the Agentic pillar.

The Agentic pillar is operationalized through 10 measurable controls.

== WAF-AGN-010 Agent Identity & Authentication

Agents must be authenticated and addressable.

== WAF-AGN-020 Tool Use Governance

Not every agent should be able to use every tool. Tool use must be approved, logged, and limited.

== WAF-AGN-030 Reasoning Transparency

Decisions must be traceable – not a black box.

== WAF-AGN-040 Memory & State Management

Memories and states must be managed consistently.

== WAF-AGN-050 Safety & Guardrails

Fail-safe, alignment, and verification must be in place.

== WAF-AGN-060 Multi-Agent Orchestration

Many agents must be coordinated.

== WAF-AGN-070 Agent Observability

Agent activities must be visible and measurable.

== WAF-AGN-080 Human-in-the-Loop

Human approval for sensitive decisions.

== WAF-AGN-090 Cost & Performance Monitoring

Agent operations must be economic and performant.

== WAF-AGN-100 Agent Debt Register

Known limitations must be documented.
