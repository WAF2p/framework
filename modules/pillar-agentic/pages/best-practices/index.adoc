= Best Practices – Agentic
:page-navtitle: Best Practices
:page-toc: right
:description: WAF++ – Best Practices für Agentic-Architekturen.

== Tool Use

Agenten müssen nur autorisierte Tools nutzen.

== Reasoning Strategies

Reasoning muss transparent und auditierbar sein.

== Memory Management

Agenten-Memory muss konsistent und sicher verwaltet werden.

== Agent Safety

Guardrails, Alignment und Fail-Safe-Mechanismen sind Pflicht.

== Cost Optimization

Agentic-Operationen müssen ökonomisch überwacht werden.
