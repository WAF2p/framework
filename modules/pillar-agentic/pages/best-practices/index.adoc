= Best Practices – Agentic
:page-navtitle: Best Practices
:page-toc: right
:description: WAF++ – Best Practices for agentic architectures.

== Tool Use

Agents must only use authorized tools.

== Reasoning Strategies

Reasoning must be transparent and auditable.

== Memory Management

Agent memory must be consistent and secure.

== Agent Safety

Guardrails, alignment, and fail-safe mechanisms are mandatory.

== Cost Optimization

Agentic operations must be economical.
