= Reasoning Strategies
:page-navtitle: Reasoning
:page-toc: right
:description: WAF++ – Reasoning-Transparenz für Agenten.

Reasoning muss:

* Nachvollziehbar sein (Chain of Thought)
* Auditierbar sein
* Transparent sein

== Logging

Jeder Entscheidungsschritt muss geloggt werden.

== Chain of Thought

Agenten sollten ihre Begründungsschritte dokumentieren.

== Best Practices

* Implementieren Sie vollständiges Inference-Logging
* Erfassen Sie Chain of Thought in den Logs
* Stellen Sie Tracing für alle Entscheidungen bereit
* Archivieren Sie Begründungs-Logs für Compliance

== Evidenz

* Logs für alle Agenten-Entscheidungen
* Tracing-Daten für Debugging
* Begründungs-Überprüfungsberichte
* Audit-Protokolle für Compliance
