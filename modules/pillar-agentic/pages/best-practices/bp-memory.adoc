= Memory Management
:page-navtitle: Memory
:page-toc: right
:description: WAF++ – Memory-Management für Agenten.

Agenten-Memory muss:

* Konsistent verwaltet werden
* Sicher gespeichert werden (Verschlüsselung)
* Mit Timestamps versehen sein

== Short-term Memory

Für aktuelle Interaktionen. Zeitbasierte Ablaufdatum.

== Long-term Memory

Persistent, aber mit Retention-Policies.

== Best Practices

* Implementieren Sie versionierten Memory-Speicher
* Verschlüsseln Sie sensible Agenten-Informationen
* Konfigurieren Sie Retention-Policies für alle Memory-Typen
* Führen Sie regelmäßige Memory-Audits durch

== Evidenz

* Versionierter Memory-Storage
* Retention-Policy-Konfiguration
* Memory-Änderungs-Protokolle
* Storage-Backup-Bestätigung
