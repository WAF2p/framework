= Memory Management
:page-navtitle: Memory
:page-toc: right
:description: WAF++ – Memory Management für Agenten.

Agenten-Memory muss:

* Konsistent verwaltet werden
* Sicher gespeichert werden (Verschlüsselung)
* Mit Timestamps versehen sein

== Short-term Memory

Für aktuelle Interaktionen. Zeitbasiertes Ablaufdatum.

== Long-term Memory

Persistent, aber mit Retention-Richtlinien.
