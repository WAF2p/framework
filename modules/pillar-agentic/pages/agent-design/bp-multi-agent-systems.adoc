== Swarm Architektur

*Homogene Agenten*, die dieselbe Aufgabe parallel bearbeiten.

== Mesh Architektur

*Heterogene Agenten* mit spezialisierten Fähigkeiten, die zusammenarbeiten.

== Comparison Matrix

|Merkmal |Swarm |Mesh
|Agenten |Homogen |Heterogen
|Kooperation |Nein (Parallel) |Ja (Kooperativ)
|Komplexität |Low |High
|Use Case |Task Parallelismus |Complex Workflows
