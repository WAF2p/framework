== Coordinator Pattern

Ein Manager-Agent koordiniert Worker-Agenten.

== Peer-to-Peer Pattern

Agenten kommunizieren direkt miteinander.

== Event-Driven Orchestration

Agenten reagieren auf Events aus einem Message Bus.

== Comparison Matrix

[cols="1,1,1,1"]
|===
|Pattern |Koordination |Skalierung |Failover

|Coordinator |Zentral |Mittel |Schwierig
|Peer-to-Peer |Distribuiert |Hoch |Einfach
|Event-Driven |Asynchron |Hoch |Einfach
|===

== Empfehlung

* Nutzen Sie Coordinator-Pattern für einfache, kontrollierte Systeme
* Wählen Sie Peer-to-Peer oder Event-Driven für hochskalierbare Systeme
* Event-Driven bietet beste Failover-Fähigkeiten
