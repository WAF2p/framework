:page-navtitle: Agent Orchestration

== Coordinator Pattern

One manager agent coordinates worker agents.

== Peer-to-Peer Pattern

Agents communicate directly with each other.

== Event-Driven Orchestration

Agents react to events from a message bus.

== Comparison Matrix

|Pattern |Coordination |Scaling |Failover
|Coordinator |Centralized |Medium |Difficult
|Peer-to-Peer |Distributed |High |Easy
|Event-Driven |Asynchronous |High |Easy
