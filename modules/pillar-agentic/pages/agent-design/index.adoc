== Core-Architekturfragen

* Single Agent oder Multi-Agent?
* Coordinator oder Peer-to-Peer?
* Closed-world oder open-world reasoning?
* Human-in-the-Loop oder fully autonomous?

== Design-Prinzipien

* Modularität: Agenten können ersetzt werden
* Observability: Jeder Schritt ist sichtbar
* Fail-Safe: Wenn Agent scheitert, was dann?
