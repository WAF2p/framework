== Core Architecture Questions

* Single agent or multi-agent?
* Coordinator or peer-to-peer?
* Closed-world or open-world reasoning?
* Human-in-the-loop or fully autonomous?

== Design Principles

* Modularity: Agents can be replaced
* Observability: Every step is visible
* Fail-safe: What if agent fails?
