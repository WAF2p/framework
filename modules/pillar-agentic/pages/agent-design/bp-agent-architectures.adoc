:page-navtitle: Agenten-Architekturen

:description: WAF++ – Architektur-Patterns für einzelne und multiple Agenten.

== Single Agent

Einzelner Agent mit klarer Verantwortung und Scope.

== Swarm Agent

Viele homogene Agenten mit gemeinsamem Ziel.

== Mesh Agent

Heterogenes Netzwerk von Spezialisten-Agenten.

== Comparison Matrix

[cols="1,1,1,2"]
|===
|Architektur |Skalierbarkeit |Komplexität |Use Case

|Single Agent |Niedrig |Niedrig |Einfache Aufgaben
|Swarm |Hoch |Mittel |Parallele Verarbeitung
|Mesh |Hoch |Hoch |Komplexe Kooperation
|===

== Empfehlung

* Beginnen Sie mit Single Agent für einfache Use Cases
* Wechseln Sie zu Swarm für skalierbare, parallele Workloads
* Nutzen Sie Mesh nur für komplexe Workflows mit mehreren Fähigkeiten
