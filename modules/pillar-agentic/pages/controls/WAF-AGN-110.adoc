== Beschreibung

Agent-generated outputs MUST be validated against schemas, business rules, or human-defined constraints before downstream use. Agent tool invocations MUST be sandboxed and restricted to an explicit allowlist of functions and parameters. High-impact actions MUST require confirmation or human-in-the-loop approval. Validation failures MUST be logged, alerted, and used to refine guardrails.

== Begründung

[cols="1,3"]
|===
|Risiko |Beschreibung

|*Risk* |Unvalidated agent outputs can trigger incorrect business decisions or data corruption.

|*Risk* |Unsandboxed tool access allows prompt injection and unauthorized actions by compromised agents.

|===

== Anforderungen

* Agent-generated outputs MUST be validated against schemas, business rules, or human-defined constraints before downstream use.
* Agent tool invocations MUST be sandboxed and restricted to an explicit allowlist of functions and parameters.
* High-impact actions MUST require confirmation or human-in-the-loop approval.
* Validation failures MUST be logged, alerted, and used to refine guardrails.

== Implementierungsleitfaden

. Document the requirement in a version-controlled policy, ADR, or standard.
. Assign ownership and establish a review cadence (e.g., quarterly).
. Implement the required configuration as code in Terraform or equivalent IaC.
