= WAF-AGN-020 – Tool Use Governance
:page-navtitle: AGN-020
:page-toc: right
:description: WAF++ – Control AGN-020: Tool Use Governance.

== Beschreibung

Nicht jeder Agent darf jedes Werkzeug nutzen. Werkzeugnutzung muss genehmigt, protokolliert und begrenzt sein.

== Anforderungen

* Tool-Whitelist/Denylist
* Genehmigungsprozess für neue Tools
* Protokollierung aller Tool-Use-Ereignisse
* Rate Limiting pro Agent

== Severity: High

== Automatisierbar: High
