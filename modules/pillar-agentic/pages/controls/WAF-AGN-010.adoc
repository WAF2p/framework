= WAF-AGN-010 – Agent Identity & Authentication
:page-toc: right
:control-id: WAF-AGN-010
:pillar: agentic
:severity: high
:category: identity-access
:automatable: High
:description: Every agent must be identifiable, authenticatable, and traceable. Agents MUST have unique, stable IDs. Authentication via token or certificate is mandatory for all agent communications. All agent interactions MUST be logged in an audit trail for security and compliance.

[.metadata]
*Säule:* Agentic | *Schweregrad:* Hoch | *Kategorie:* Identity Access | *Automatisierbar:* High

== Beschreibung

Every agent must be identifiable, authenticatable, and traceable. Agents MUST have unique, stable IDs. Authentication via token or certificate is mandatory for all agent communications. All agent interactions MUST be logged in an audit trail for security and compliance.

== Begründung

[cols="1,3"]
|===
|Risiko |Beschreibung

|*Risk* |Non-identifiable agents cannot be traced or held accountable for their actions.

|*Risk* |Missing agent authentication enables identity spoofing and non-attributable changes.

|===

== Anforderungen

* Every agent must be identifiable, authenticatable, and traceable.
* Agents MUST have unique, stable IDs.
* All agent interactions MUST be logged in an audit trail for security and compliance.

== Implementierungsleitfaden

1. Document the requirement in a version-controlled policy or standard.
2. Assign ownership and establish a review cadence (e.g., quarterly).
3. Implement the required configuration as code in Terraform or equivalent IaC.

== Checks

=== waf-agn-010.tf.aws.bedrock-agent-id-defined

*Engine:* `terraform` | *Provider:* aws | *Automated:* Ja

*AWS Bedrock agents must have unique identifiers and authentication*

AWS Bedrock agents must have a unique, stable agent_id and authentication via IAM roles or API keys. All agent interactions must be logged via CloudWatch.

*Scope:* `resource` — `aws_bedrockagent`

*Assertions:*
* `agent_name` not empty — Agent must have a unique name/identifier.
* `agent_resources` attribute exists — Agent must have resources configured.

*Remediation:* Define an aws_bedrockagent resource with a unique agent_id and associate it with an IAM role for authentication. Enable CloudWatch logging for agent interactions.

.Compliant

[source,terraform]
----
resource "aws_bedrockagent" "customer_support_agent" {
  agent_name = "customer-support-agent"
  description = "Agent for customer support inquiries"
  agent_resources = [{
    model_arn = aws_bedrock_foundation_model.claude.arn
  }]
  # Unique agent_id automatically assigned
  # Authentication via IAM role
}
resource "aws_cloudwatch_log_group" "agent_logs" {
  name = "/aws/bedrock/customer-support-agent"
}
----

.Non-Compliant

[source,terraform]
----
# No agent defined – unauthenticated agent access
# WAF-AGN-010 Violation
# Agents without IDs and authentication are not permitted
----

*Azure AI agents must have unique identifiers and authentication*

Azure AI agents must have unique agent_id and authentication via Azure AD or Managed Identity. All interactions must be logged via Application Insights.

*Scope:* `resource` — `azurerm_cognitive_deployment`

*Assertions:*

----

  model_name                 = "gpt-4"

resource "azurerm_application_insights" "agent_ai" {
  name                = "agent-insights"
  resource_group_name = azurerm_resource_group.main.name
  location            = azurerm_resource_group.main.location
  workspace_id        = azurerm_log_analytics_workspace.main.id
}
----
