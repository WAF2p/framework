= WAF-AGN-010 – Agent Identity & Authentication
:page-navtitle: AGN-010
:page-toc: right
:description: WAF++ – Control AGN-010: Agent Identity & Authentication.

== Beschreibung

Jeder Agent muss identifizierbar, authentifizierbar und nachvollziehbar sein.

== Anforderungen

* Agenten-ID ist unique und stabil
* Authentifizierung über Token oder Zertifikate
* Audit-Log für alle Agenten-Interaktionen

== Severity: High

== Automatisierbar: High
