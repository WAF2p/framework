= Agentic – Architectural Patterns
:page-toc: right
:description: WAF++ – Typical architectural patterns for agentic systems.

== Single Agent Architecture

Single agent with clear responsibility.

*Pros*: Simplicity, fast implementation
*Cons*: Limited complexity

== Multi-Agent Orchestration

Coordinator/Manager steers worker agents.

*Pros*: Scalability, specialization
*Cons*: Complexity in orchestration

== Agent Mesh

Heterogeneous network of agents with specialized capabilities.

*Pros*: Flexibility, expertise
*Cons*: High complexity, governance challenges

== Human-in-the-Loop

Human approval for sensitive decisions.

== Recommendation for Start

Start with single agent or small swarm. Full mesh only makes sense late.
