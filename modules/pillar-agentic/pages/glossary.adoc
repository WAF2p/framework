= Glossary (Agentic)
:page-toc: right
:toclevels: 2
:description: WAF++ Agentic – Glossary of key terms for autonomous AI agents and multi-agent systems.

This glossary defines terms used in the Agentic pillar of WAF++.

---

== A

=== Agent
An autonomous or semi-autonomous AI system that pursues goals, makes plans, uses tools, and acts in an environment. WAF++ requires every agent to have a unique identity, authentication, and auditability.
Related: xref:controls/WAF-AGN-010.adoc[WAF-AGN-010].

=== Agent Debt
Known limitations or failure modes of an agent (knowledge cutoff, tool gaps, accuracy issues). The Agent Debt Register documents and prioritizes these limitations.
Related: xref:controls/WAF-AGN-100.adoc[WAF-AGN-100].

=== Agent Mesh
A network of heterogeneous agents with specialized roles that cooperate through defined interfaces.
Related: xref:controls/WAF-AGN-060.adoc[WAF-AGN-060].

=== Agent Orchestration
Coordination of multiple agents across architecture and process boundaries, including task assignment, event communication, and failure recovery.
Related: xref:controls/WAF-AGN-060.adoc[WAF-AGN-060].

=== Alignment
Consistency of an agent's behavior with human values, organizational rules, and regulatory requirements. Verified through guardrails, tests, and human-in-the-loop checks.
Related: xref:controls/WAF-AGN-050.adoc[WAF-AGN-050].

---

== C

=== Chain-of-Thought
Explicit recording of the intermediate steps a model goes through when making a decision. Important for debugging, explainability, and compliance.
Related: xref:controls/WAF-AGN-030.adoc[WAF-AGN-030].

---

== E

=== Emergent Behavior
Behavior that arises from the interaction of multiple agents and was not explicitly programmed. Can be creative or risky.
Related: xref:controls/WAF-AGN-050.adoc[WAF-AGN-050], xref:controls/WAF-AGN-060.adoc[WAF-AGN-060].

---

== F

=== Function Calling
Capability of a model to generate structured calls to external functions or APIs. Foundation of tool use in agents.
Related: xref:controls/WAF-AGN-020.adoc[WAF-AGN-020].

---

== G

=== Guardrails
Safety and policy mechanisms that constrain agent outputs and actions. Include content filters, action boundaries, rate limiting, and fail-safes.
Related: xref:controls/WAF-AGN-050.adoc[WAF-AGN-050].

---

== H

=== Human-in-the-Loop
Human review or approval before the execution of critical agent actions. Ensures accountability and compliance.
Related: xref:controls/WAF-AGN-080.adoc[WAF-AGN-080].

---

== L

=== LLM
Large Language Model. A transformer-based language model with a large parameter count that enables reasoning, planning, and text generation.

---

== M

=== Model Card
Document describing a model's capabilities, limitations, training data, evaluation results, and usage risks. Supports transparent model selection and compliance.

=== Multi-Agent System
A system with multiple agents that cooperate or interact in defined roles. Requires orchestration and clear communication.
Related: xref:controls/WAF-AGN-060.adoc[WAF-AGN-060].

---

== O

=== Orchestrator
A specialized agent that controls other agents, delegates tasks, and monitors overall progress.
Related: xref:controls/WAF-AGN-060.adoc[WAF-AGN-060].

---

== P

=== Planning Horizon
Temporal and complexity scope of the planning an agent can perform. Ranges from single-step actions to long-term, multi-step plans.

=== Prompt Injection
Attack in which inputs are manipulated so that a model performs unintended actions. Countermeasures include input/output filtering and strict tool permissions.
Related: xref:controls/WAF-AGN-020.adoc[WAF-AGN-020], xref:controls/WAF-AGN-050.adoc[WAF-AGN-050].

---

== R

=== Reasoning Trace
Complete, time-ordered record of an agent's decision-making. Essential for audit and debugging.
Related: xref:controls/WAF-AGN-030.adoc[WAF-AGN-030], xref:controls/WAF-AGN-070.adoc[WAF-AGN-070].

---

== S

=== Swarm
Many homogeneous agents working in parallel and decentralized toward a shared goal.
Related: xref:controls/WAF-AGN-060.adoc[WAF-AGN-060].

---

== T

=== Tool Use
An agent's ability to invoke external tools, APIs, or code runners. Must be governed through whitelists, schemas, and logging.
Related: xref:controls/WAF-AGN-020.adoc[WAF-AGN-020].
