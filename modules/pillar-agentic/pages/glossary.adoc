= Glossary – Agentic
:page-navtitle: Glossary
:page-toc: right
:description: WAF++ – Terms of the Agentic pillar.

== A

* *Agent*: An autonomous or semi-autonomous AI system that can plan and execute tasks
* *Agent Mesh*: A network of heterogeneous agents with specialized capabilities
* *Agent Orchestration*: The coordination of multiple agents across architecture

== M

* *Multi-Agent System*: A system with multiple agents that cooperate or compete

== O

* *Orchestrator*: An agent that steers other agents

== S

* *Swarm*: Many homogeneous agents with shared goal

== T

* *Tool Use*: The ability of an agent to use APIs and systems
