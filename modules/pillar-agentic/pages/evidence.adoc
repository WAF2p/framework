:page-navtitle: Evidence & Audit

:description: WAF++ – Evidence requirements for agentic architectures.

== Audit Requirements

* Agent logs: Every decision must be traceable
* Tool-use logs: Every tool use must be logged
* Human-in-the-loop: Approvals must be documented
* Safety audits: Regular review of guardrails

== Evidence Sources

* Agent telemetry
* API logs
* Human approvals (timestamped)
* Safety-check results
