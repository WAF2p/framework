== Audit-Anforderungen

* Agenten-Logs: Jede Entscheidung muss nachvollziehbar sein
* Tool-Use-Logs: Jede Werkzeugnutzung muss protokolliert sein
* Human-in-the-Loop: Genehmigungen müssen dokumentiert sein
* Safety-Audits: Regelmäßige Überprüfung der Guardrails

== Evidenz-Quellen

* Agenten-Telemetrie
* API-Logs
* Human approvals (timestamped)
* Safety-check results
