= WAF++ Controls (Maschinenlesbare YAML-Controls)
:page-navtitle: Controls-Übersicht
:page-toc: right

Dieses Modul enthält alle maschinenlesbaren Controls des WAF++ Frameworks als YAML-Dateien.
Die Controls können direkt vom WAF++ Checker Tool gegen Terraform-Code ausgeführt werden.

|`WAF-SEC-xxx`
|xref:pillar-security:controls.adoc[Controls (Security)]

|2 · Cost Optimization
|`WAF-COST-xxx`
|xref:pillar-cost:controls.adoc[Controls (Cost Optimization)]

|3 · Performance Efficiency
|`WAF-PERF-xxx`
|xref:pillar-efficiancy:controls.adoc[Controls (Performance Efficiency)]

|4 · Reliability
|`WAF-REL-xxx`
|xref:pillar-reliability:controls.adoc[Controls (Reliability)]

|5 · Operational Excellence
|`WAF-OPS-xxx`
|xref:pillar-excellence:controls.adoc[Controls (Operational Excellence)]

|6 · Sustainability
|`WAF-SUS-xxx`
|xref:pillar-sustainability:controls.adoc[Controls (Sustainability)]

|7 · Sovereign
|`WAF-SOV-xxx`
|xref:pillar-sovereign:controls.adoc[Controls (Sovereign)]

|8 · Agentic
|`WAF-AGN-xxx`
|xref:pillar-agentic:controls.adoc[Controls (Agentic)]

* Eine YAML-Datei pro Control unter `modules/controls/controls/`
* IDs folgen dem Schema `+WAF-{PILLAR}-{NNN}+` (z. B. `WAF-COST-010`, `WAF-SOV-020`, `WAF-AGN-030`)
* Der vollständige Katalog mit Details ist unter xref:catalog.adoc[Controls-Katalog] verfügbar
