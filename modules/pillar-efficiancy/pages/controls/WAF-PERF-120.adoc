== Description

All production databases MUST enable query performance insights, slow-query logging, or execution plan analysis. Slow queries exceeding defined latency thresholds MUST be reviewed monthly and optimized. Indexes MUST be justified by query patterns and revisited as access patterns evolve. Query review results MUST be documented in a performance register.

== Rationale

[cols="1,3"]
|===
|Risk |Description

|*Risk* |Unreviewed slow queries accumulate until they become critical latency or availability incidents.

|*Risk* |Missing indexes force full table scans, increasing cost and degrading user experience.

|===

== Requirements

* All production databases MUST enable query performance insights, slow-query logging, or execution plan analysis.
* Slow queries exceeding defined latency thresholds MUST be reviewed monthly and optimized.
* Indexes MUST be justified by query patterns and revisited as access patterns evolve.
* Query review results MUST be documented in a performance register.

== Implementation Guidance

. Document the requirement in a version-controlled policy, ADR, or standard.
. Assign ownership and establish a review cadence (e.g., quarterly).
. Implement the required configuration as code in Terraform or equivalent IaC.
